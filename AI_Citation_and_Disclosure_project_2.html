Claude was used for the following purposes during this project:

  • Topic and data selection: brainstorming project topics and identifying public mortgage datasets, including HMDA data from the Consumer Financial Protection Bureau and the Freddie Mac Single-Family Loan-Level Dataset.
  • Data profiling: running summaries of the uploaded HMDA files, including record counts, approval rates by loan purpose and property type, missing-value checks, and distributions of individual fields.
  • Problem design: defining the binary approval target, the sample filters (first lien, owner-occupied, one-to-four family site-built homes), the feature list, and the fields to exclude for leakage, redundancy, or lack of information.
  • Code generation: writing Python code for exploratory visualizations, data cleaning and feature engineering, the scikit-learn preprocessing pipeline, the baseline, logistic regression, and random forest models, hyperparameter tuning, evaluation metrics and charts, model interpretation, and the fairness audit.
  • Explanation of concepts: explaining log transforms, preprocessing pipelines, random seeds, hyperparameter tuning (including C, max_depth, and min_samples_leaf), ROC-AUC, denial recall and precision, and multicollinearity.
  • Feedback on writing: reviewing drafts of the introduction and analysis sections for accuracy and clarity, and suggesting revised wording.
  • Code review: reviewing the project notebook for errors, missing rubric requirements, and reproducibility issues.
  • Sources: locating peer-reviewed research on mortgage refinancing after the 2008 financial crisis and formatting APA citations.

All AI-generated code was run and checked against the data, and all sources were reviewed before citation. Final modeling decisions, interpretation, and written conclusions are the author’s own.
